Sem GitHub: pelo .zip

  1. Baixe o .zip e descompacte.
  2. Abra o terminal ao lado da pasta oficio-inteiro e rode claude.
  3. Cole: 
    /plugin marketplace add ./oficio-inteiro
/plugin install oficio-inteiro@oficio-inteiro
  4. Reinicie e digite /.

No Grok Bot

  1. Abra uma skill do .zip, ex.: skills/rotina-do-dia/SKILL.md.
  2. Copie o texto e cole no chat com: 
    Salve isto como uma skill. Mostre antes de salvar.
  3. Repita para as skills que quiser.

Dúvidas

Preciso saber programar?

Não. Você conversa em português. O Claude Code (ou o Grok Bot) faz o resto.

Quanto custa?

O núcleo é grátis. Você só paga a ferramenta de IA que já usa (Claude ou Grok), direto ao fornecedor.

Funciona fora do Claude Code?

As skills funcionam no Grok Bot. Codex e Cursor leem o AGENTS.md, sem garantia de tudo funcionar igual.

Substitui contador ou terapeuta?

Não. O kit organiza e faz boas perguntas. Imposto é estimativa para levar ao contador.

Como desinstalar?

No Claude Code: /plugin uninstall oficio-inteiro@oficio-inteiro. Sua pasta pessoal continua sua.
