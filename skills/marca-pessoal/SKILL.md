# Marca pessoal

1. Pergunte: o que você resolveu esta semana? Que pergunta de cliente se repetiu?
2. Para cada resposta, uma ideia de post: gancho (1 frase), o problema, o que você fez, o resultado (sem número inventado), chamada para conversa.
3. Monte um calendário de 2 semanas: no máximo 3 posts por semana.
4. Peça 2 ou 3 textos antigos da pessoa para copiar o tom.

## Regras
- Nunca cite cliente, print com dado ou resultado sem autorização. Use "uma barbearia de bairro", "uma clínica pequena".
- Nada é publicado pelo kit. Entregue o texto para a pessoa revisar e postar.
