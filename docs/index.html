Instale em 1 passo

Cole no Claude Code e digite /oficio:comecar.

Claude Code 
/plugin marketplace add codetradeai/oficio
/plugin install oficio@oficio

Repositório: github.com/codetradeai/oficio

Sem GitHub: pelo .zip

  1. Baixe o .zip e descompacte (pasta oficio).
  2. Abra o terminal ao lado da pasta e rode claude.
  3. Cole: 
    /plugin marketplace add ./oficio
/plugin install oficio@oficio
  4. Reinicie e digite /oficio:comecar.

No Grok Bot

  1. Abra uma skill do .zip, ex.: skills/rotina-do-dia/SKILL.md.
  2. Copie o texto e cole no chat com: 
    Salve isto como uma skill. Mostre antes de salvar.
  3. Repita para as skills que quiser.

Dúvidas

Preciso saber programar?

Não. Você conversa em português. O Claude Code (ou o Grok Bot) faz o resto.

Quanto custa?

O Ofício é grátis. Você só paga a ferramenta de IA que já usa, direto ao fornecedor.

Eu usava o Ofício Inteiro. E agora?

Instale o oficio. Na primeira sessão, sua pasta antiga é copiada para a nova, sem apagar nada.

Funciona fora do Claude Code?

As skills funcionam no Grok Bot. Codex e Cursor leem o AGENTS.md, sem garantia de tudo funcionar igual.

Como desinstalar?

No Claude Code: /plugin uninstall oficio@oficio. Sua pasta pessoal continua sua.
