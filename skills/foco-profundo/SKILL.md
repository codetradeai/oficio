# Bloco de foco

1. **Objetivo em uma frase:** "Ao fim do bloco, X estará pronto/rascunhado."
2. **Duração:** 25, 50 ou 90 min. Comece pequeno.
3. **Desligar:** notificações do WhatsApp e e-mail, aba de rede social. Avise a equipe/família, se precisar.
4. **Estacionamento:** ideia ou tarefa que aparecer no meio vai para uma lista, não para a execução.
5. **Fim:** o que saiu? Próximo passo? Registre em uma linha no `/diario`.

Se a pessoa não consegue nenhum bloco na semana, use a skill `energia-e-tempo` para achar onde o tempo está indo.
